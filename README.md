# IPC Parser — Парсер Международной патентной классификации (МПК)

[![Python](https://img.shields.io/badge/Python-3.8%2B-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![IPC Version](https://img.shields.io/badge/IPC-2026.01-orange.svg)](https://www.wipo.int/classifications/ipc/)

Инструмент для парсинга официальных XML-файлов Международной патентной классификации (МПК / IPC) с сайта [WIPO](https://www.wipo.int/classifications/ipc/) и преобразования их в удобные для работы форматы: **Excel**, **JSON**, **SQLite**.

> 🇬🇧🇷🇺 Поддерживает двуязычный вывод: английский (оригинал) и русский (машинный перевод через LLM).

## ✨ Возможности

- 🔍 **Парсинг XML МПК** — чтение официальных файлов с сайта WIPO (формат `ipc_scheme_YYYYMMDD.xml`)
- 🌳 **Разворачивание иерархии** — каждая запись содержит ссылку на родительскую рубрику
- 📝 **«Схлопывание» заголовков** — полный читаемый заголовок с учётом всех уровней иерархии (точки → полный текст)
- 🌐 **Автоматический перевод** — перевод всех заголовков на русский язык через API LLM (Timeweb Cloud / OpenAI-совместимые)
- 💾 **Кеширование переводов** — повторные запуски не требуют повторного перевода
- 📊 **Несколько форматов вывода** — Excel, JSON, SQLite
- 🏷️ **Классификация записей** — Section, Class, Subclass, MainGroup, Subgroup
- 🔖 **Остаточные рубрики** — автоматическое определение рубрик вида «...не предусмотренные в других группах»
- 📌 **Совместимость с Excel** — данные оптимизированы для `ВПР()`, фильтров и сводных таблиц

## 🚀 Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/your-username/ipc-parser.git
cd ipc-parser
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

**Содержимое `requirements.txt`:**

```
pandas>=1.3.0
openpyxl>=3.0.0
lxml>=4.6.0
openai>=1.0.0
tqdm>=4.60.0
```

> 💡 Для работы перевода нужен API-ключ. По умолчанию используется [Timeweb Cloud](https://timeweb.cloud/), но подойдёт любой OpenAI-совместимый провайдер.

### 3. Скачивание XML-файла МПК

Скачайте актуальную версию с официального сайта WIPO:

```
https://www.wipo.int/classifications/ipc/en/ITsupport/Version20260101/
```

Файл: `ipc_scheme_20260101.xml` (или аналогичный для нужной версии).

## ⚡ Быстрый старт

### Базовое использование (только Excel, английский)

```bash
python ipc_parser.py
```

На выходе: `IPC_Flat_20260101.xlsx` с вкладкой `IPC_Scheme`.

### С переводом на русский

Убедитесь, что в скрипте указан ваш API-ключ:

```python
client = OpenAI(
    api_key="ваш-api-ключ",
    base_url="https://api.timeweb.ai/v1",
)
```

Запустите:

```bash
python ipc_parser_translate.py
```

На выходе: `IPC_Flat_20260101.xlsx` с двумя вкладками:
- `IPC_Scheme_EN` — английская версия
- `IPC_Scheme_RU` — русская версия

### Продвинутый запуск (все форматы)

```bash
python ipc_parser.py --input ipc_scheme_20260101.xml --output ipc_data --formats xlsx,json,sqlite
```

## 📦 Форматы вывода

| Формат | Статус | Описание |
|--------|--------|----------|
| **XLSX** | ✅ Готов | Две вкладки (EN/RU), автофильтры, закреплённые заголовки |
| **JSON** | 🔄 В разработке | Плоский JSON-массив + иерархический JSON |
| **SQLite** | 📋 Планируется | Полнотекстовый поиск, индексы для быстрых запросов |

### Структура JSON (плоский формат)

```json
[
  {
    "Level": 4,
    "Kind": "u",
    "Type": "Subclass",
    "Symbol": "A01B",
    "ParentSymbol": "A01",
    "DotCount": 0,
    "Section": "A",
    "Class": "A01",
    "Subclass": "A01B",
    "MainGroup": "A01B",
    "IsResidual": false,
    "FullTitle_EN": "SOIL WORKING IN AGRICULTURE OR FORESTRY; PARTS, DETAILS...",
    "FullTitle_RU": "ОБРАБОТКА ПОЧВЫ В СЕЛЬСКОМ И ЛЕСНОМ ХОЗЯЙСТВЕ; ЧАСТИ, ДЕТАЛИ..."
  }
]
```

## 📊 Структура выходных данных

| Столбец | Тип | Описание | Пример |
|---------|-----|----------|--------|
| `Level` | int | Уровень иерархии (1-5) | `4` |
| `Kind` | str | Код типа рубрики | `u` (subclass), `m` (group) |
| `Type` | str | Тип рубрики | `Subclass`, `MainGroup`, `Subgroup` |
| `Symbol` | str | Полный индекс МПК | `A01B 1/00` |
| `ParentSymbol` | str | Индекс родительской рубрики | `A01B` |
| `DotCount` | int | Количество точек (глубина вложенности) | `2` |
| `Section` | str | Раздел (A-H) | `A` |
| `Class` | str | Класс | `A01` |
| `Subclass` | str | Подкласс | `A01B` |
| `MainGroup` | str | Основная группа | `A01B 1/00` |
| `IsResidual` | bool | Признак остаточной рубрики | `False` |
| `FullTitle_EN` | str | Полный заголовок (EN) | `Hand tools → Spades; Shovels` |
| `FullTitle_RU` | str | Полный заголовок (RU) | `Ручные орудия → Заступы; Лопаты` |

## ⚙️ Конфигурация

Основные настройки в начале скрипта `ipc_parser.py`:

```python
# Файлы
INPUT_XML = "ipc_scheme_20260101.xml"
OUTPUT_XLSX = "IPC_Flat_20260101.xlsx"
TRANSLATION_CACHE = "ipc_translation_cache.json"

# Параметры перевода
BATCH_SIZE = 30              # Фраз в одном запросе к API
DELAY_BETWEEN_BATCHES = 1    # Задержка между запросами (сек)
ENABLE_TRANSLATION = True    # Включить/выключить перевод

# API-ключ
API_KEY = "ваш-ключ"
API_BASE_URL = "https://api.timeweb.ai/v1"
```

## 🔧 Как это работает

### Архитектура парсера

```
┌─────────────────────────────────────────────────────────┐
│                    IPC Parser                            │
├─────────────────────────────────────────────────────────┤
│  1. XML Parser (lxml)                                   │
│     ├── Чтение ipcEntry                                 │
│     ├── Извлечение symbol, kind, textBody               │
│     └── Определение иерархии по точкам                 │
│                                                         │
│  2. Translation Engine (OpenAI API)                     │
│     ├── Сбор уникальных фраз                           │
│     ├── Батчевый перевод                               │
│     └── Кеширование в JSON                             │
│                                                         │
│  3. Output Formatters                                   │
│     ├── XLSX (openpyxl)                                 │
│     ├── JSON (json)          ← в разработке            │
│     └── SQLite (sqlite3)     ← планируется             │
└─────────────────────────────────────────────────────────┘
```

### Схема иерархии МПК

```
Раздел (Section)         A
  └── Класс (Class)      A01
       └── Подкласс (Subclass)  A01B
            ├── Основная группа (MainGroup)  A01B 1/00
            │    ├── Подгруппа (Subgroup)    A01B 1/02  (. 1 точка)
            │    │    └── Подгруппа          A01B 1/04  (. . 2 точки)
            │    └── Подгруппа               A01B 1/06  (. 1 точка)
            └── Основная группа              A01B 3/00
```

## ❓ Часто задаваемые вопросы

### Где взять XML-файл МПК?

Скачайте с официального сайта WIPO:
```
https://www.wipo.int/classifications/ipc/en/ITsupport/Version20260101/
```
Нужен файл вида `ipc_scheme_YYYYMMDD.xml`.

### Можно ли использовать другой API для перевода?

Да! Замените параметры в строке:

```python
client = OpenAI(
    api_key="ваш-ключ",
    base_url="https://ваш-провайдер/v1",
)
```

Подойдёт любой OpenAI-совместимый API (DeepSeek, OpenRouter, локальный LM Studio и т.д.).

### Сколько времени занимает перевод?

~80 000 уникальных фраз переводятся за 20-40 минут (зависит от скорости API). При повторном запуске — мгновенно (используется кеш).
